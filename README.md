## 🌟 أبرز مميزات المشروع (Key Features)

### 1. واجهة مستخدم صيدلانية باللغة العربية ودعم كامل لـ RTL
- خطوط طبية حديثة ومريحة للعين (**Tajawal** و **Plus Jakarta Sans**).
- اتجاه كامل من اليمين إلى اليسار (`dir="rtl"`) مع ألوان طبية معتمدة (أبيض نقي، كحلي سريري `#0284c7`، وأخضر زمردي `#10b981`).
- شعار فيكتور مخصص وأيقونة تبويب متصفح (`favicon.svg`) لعلامة التبويب.

### 2. محرك بحث ذكي وسريع (Live Clinical Search)
- بحث فوري في أسماء الأدوية التجارية، الأسماء العلمية الإنجليزية، والمواد الفعالة (Active Ingredients).
- شريط نتائج منسدل تفاعلي يعرض الصورة والسعر والقسم فور الكتابة.

### 3. كتالوج المنتجات وفلاتر التصفية المتطورة (Advanced Catalog & Filters)
- تصنيف حسب الأقسام (الأدوية العلاجية، الفيتامينات، العناية بالبشرة، الأجهزة والمستلزمات، رعاية الأم والطفل).
- فلاتر جانبية حسب:
  - نوع الوصفة: أدوية بدون وصفة (OTC) مقابل أدوية تستلزم روشتة (Rx).
  - النطاقات السعرية وتوافر المخزون.
  - خيارات الترتيب (الأكثر طلباً، الأقل سعراً، الأعلى سعراً، أعلى تقييم).
- نافذة تفاصيل دواء تفاعلية تشمل: المادة الفعالة، الجرعة، طريقة الاستخدام، والتحذيرات وموانع الاستعمال.

### 4. وحدة رفع ومراجعة الروشتة الطبية (Prescription Upload Module)
- سحب وإفلات لصور الروشتات وملفات PDF مع معاينة فورية.
- نموذج تجريبي جاهز للاختبار الفوري السريع.
- إصدار رقم تذكرة استلام آلي (مثل `#RX-84920`) مع إمكانية المتابعة المباشرة عبر الواتساب على رقم `01149556339`.
- خيار الموافقة المسبقة على البدائل الدوائية المعتمدة علمياً في حال نقص الصنف الأصلي.

### 5. خدمة طلب الأدوية الناقصة والمستوردة (Special Medicine Request)
- تسجيل طلبات الأدوية غير المتوفرة في السوق لتتولى الصيدلية توفيرها من مخازن ومستودعات الأدوية مع رقم طلب خاص (`#REQ-...`).

### 6. سلة المشتريات ونظام الدفع المتعدد (Cart & Checkout Drawer)
- درج سلة منزلق يعرض مؤشر التقدم نحو الشحن المبرد المجاني.
- كوبون خصم فعال: كود `MOAMEN10` لخصم 10% فوري.
- خيارات دفع واقعية:
  1. **الدفع نقداً عند الاستلام (Cash on Delivery).**
  2. **البطاقات البنكية (فيزا، ماستركارد، وميزة).**

## 🚀 طريقة التثبيت والتشغيل محلياً (Local Setup)

```bash
# 1. استنساخ المستودع
git clone https://github.com/avatarpP0/healthcare-e-commerce-web.git

# 2. الدخول إلى مجلد المشروع
cd healthcare-e-commerce-web

# 3. تثبيت الاعتماديات
npm install --legacy-peer-deps

# 4. تشغيل خادم التطوير
npm run dev
```

التطبيق سيعمل مباشرة على: `http://localhost:3000`

## ☁️ إرشادات الرفع على Vercel (Vercel Deployment)

المشروع مهيأ تماماً للرفع على منصة **Vercel** من خلال الملفات التالية المضمنة:
- `vercel.json`: يحتوي على أوامر البناء وإعادة التوجيه (SPA Routing) لتفادي خطأ 404.
- `.npmrc`: مضبوط تلقائياً على `legacy-peer-deps=true` لمنع أي تعارض في حزم Vite.

### خطوات الرفع:
1. اربط حساب GitHub بمنصة **[Vercel](https://vercel.com)**.
2. اختر مستودع `healthcare-e-commerce-web`.
3. اضغط على **Deploy** دون الحاجة لتغيير أي إعدادات، حيث ستقوم Vercel تلقائياً بقراءة `vercel.json` وتشغيل:
   - **Install Command:** `npm install --legacy-peer-deps`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
